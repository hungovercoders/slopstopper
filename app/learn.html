🎓 The course

From zero to slopstopper

Twenty-one short lessons, one check or one idea at a time: the slop it stops, the tool behind it, what it looks like when it fires, and the fix. You start with nothing installed and finish able to read any check's red line, fix what it found, tailor the suite to a repo, and add a check of your own.

You will need

Python, the CLI and a demo repo.

Every lesson but the last runs in a small repo the CLI writes for you: "Lantern", a status page with one deliberate finding per check. Python 3.11 or newer, then:

pipx install slopstopper-cli
slopstopper demo                   # writes slopstopper-demo/
cd slopstopper-demo
git init -q -b main && git add -A && git commit -q -m "lantern"

Each lesson says which tool it needs beyond the CLI, and slopstopper doctor lists what is missing. Lesson 20 edits the CLI itself, so it runs in a checkout of the repository; the syllabus has the setup for it. Every lesson is also a markdown file in that directory, which is what the pages here are rendered from.

The lessons

Read them in order, or jump to a check.

Each lesson has the same shape: why the check exists, the commands to type and the output to expect, a checkpoint, and an exercise. The commands on every page run in CI, so they work as written. Start with lesson 0, or jump to the check you came for.
