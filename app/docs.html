Security scanning and controls for this project: what each security: check looks at, how it blocks, and where to tune it. One file per check; this page is the map, so read only the doc whose trigger matches.

  • API Headers & CORSThe API-shaped analogue of CSP Exceptions. On an HTML surface, CSP is the header that decides what a document may load. On a JSON API there is no document to restrict, so CSP is largely irrelevant and CORS becomes the control that decides who may read the response. A permissive CORS policy on a…
  • CSP exceptionsThis file is the single source of truth for every per-path Content-Security-Policy relaxation on the SlopStopper site. The ss:hygiene:csp-exceptions check fails the build if worker/headers.json and this file disagree.
  • Dynamic Application Security Testing (DAST)slopstopper ships automated Dynamic Application Security Testing (DAST) using OWASP ZAP to detect runtime security issues by scanning your running site. This guide explains how to customise and use the check.
  • Licence Inventorysecurity:licences judges every dependency the lockfiles resolve to against the repo's licence allowlist, so a transitive package under a denied licence cannot sit in the tree unnoticed. It is the full-tree companion to the dependency review, which judges only what each PR adds.
  • Static Application Security Testing (SAST)slopstopper ships automated Static Application Security Testing (SAST) using Semgrep to detect security bugs and anti-patterns in your own source code. This guide explains how to customise and use the check.
  • Secrets Detectionslopstopper ships automated secrets detection using Gitleaks to identify hardcoded credentials, API keys, and other sensitive data in your source code and git history. This guide explains how to customise and use the check.
  • Dependency Vulnerability Scanningslopstopper ships automated dependency vulnerability scanning using Trivy to detect known CVEs in your project's dependencies. This guide explains how to customise and use the check.

Support

How to get help with this project.

Working with an agent

Let the agent install it and fix what it finds.

Two Claude Code skills ship with the suite: slopstopper-install adds the suite to a repo or refreshes it, and slopstopper-triage takes a red check from the workflow to the report to the fix. Installing the skills covers both; the steward runs them across every repo in an organisation. An assistant reading this site can start from llms.txt, which lists every page with a one-line summary.
