📚 Docs · The course

From zero to slopstopper

  1. Docs
  2. The course

A course in twenty-one short lessons, each with a YouTube episode to follow. You start with nothing installed and finish able to install the suite into a repo, read any check's red line and the report it points at, fix what it found, tailor the suite to a repo's shape, and add a check of your own. Every lesson explains one check or one idea on its own terms: the slop it stops, the tool behind it, what it looks like when it fires, and the fix.

You will need

Every lesson but the last runs in a small repo the CLI writes for you, so they need the CLI and nothing of this repository. Python 3.11 or newer, then:

pipx install slopstopper-cli       # or: pip install --user slopstopper-cli
slopstopper demo                   # writes slopstopper-demo/, a status page with one finding per check
cd slopstopper-demo
git init -q -b main && git add -A && git commit -q -m "lantern"

The demo is "Lantern", a two-page status page laid out the way the suite expects, deliberately a little slopped: each check lesson opens on a red check already in it, reads the report, fixes the finding, and puts the demo back with git checkout. The commit is what lesson 6 scans. The lessons about the suite itself (1, 17, 18 and 19: the installer, the workflows, the skills and profiles) install the suite into the same demo with slopstopper install, which writes it from the files the CLI ships, and put it back afterwards. Each lesson says which external tool it needs beyond the CLI (lesson 6 gitleaks, lesson 7 semgrep, lesson 8 trivy, lesson 10 Docker, lessons 9 to 15 node, and for the browser checks in 11 to 15 one npm install in the demo followed by npx playwright install chromium); slopstopper doctor lists what is missing.

Lesson 20 edits the CLI's source, so it alone runs in a checkout of this repository. For that one, mise must be installed and activated in your shell, then:

git clone https://github.com/hungovercoders/slopstopper.git
cd slopstopper
mise install                       # task and node, pinned in mise.toml
task contributing:setup            # the CLI (editable, in cli/.venv), npm deps, Chromium, the hook
export PATH="$PWD/cli/.venv/bin:$PATH"
slopstopper --version

The task ss:* shims call whichever slopstopper is on PATH; that last export points them at the editable install so the lesson runs HEAD. Lesson 0 reads from either.

How the lessons work

Each lesson is one page with the same shape, so you always know where you are:

SectionWhat it is for
GoalOne sentence: what you can do when you finish.
Why this checkThe slop it stops and the tool behind it.
You will needWhich of the two sandboxes above, and any tool beyond the CLI.
StepsNumbered, each with the command to type and the output to expect. Copy, paste, compare. Most check lessons run the same loop: red on the demo as shipped, read the report, fix, green, put the demo back.
CheckpointOne command whose output proves the lesson took.
ExerciseOne task to do on your own, with a collapsed solution.
Going furtherLinks into the docs for the depth the lesson skipped.
Episode scriptCollapsed at the end: what the video says and shows, with chapter timestamps.

Runnable blocks are marked, and task contributing:learn:check runs them in order in a sandbox (the demo repo or a scratch clone, as each lesson's marker says), locally and in CI (on every push to main, nightly, and on a pull request that changes the course), so a lesson cannot quietly stop working when the CLI changes. The sample output comes from the build the lesson was written against; a later release can word a hint differently, but the commands and the verdicts are the same.

The course is read on the site: slopstopper.dev/learn.html lists the lessons and each one is a page under /learn/, rendered from the file linked here by task contributing:learn:site. The episode column links the video once it is recorded. The title, thumbnail and description every episode follows are in EPISODES.md, and docs/learn/tapes/NN.tape holds each lesson's terminal parts, generated from its runnable blocks.

Start with lesson 0, or jump to lesson 2 if you already know why you are here and have the demo above.

Writing a lesson

Copy TEMPLATE.md, which is the lesson shape and the rules a lesson follows. When the page is written, task contributing:learn:site renders it onto the site and task contributing:learn:tapes writes its tape; the CLI's test suite fails while either is stale. The course lives under docs/learn/ but is listed in hygiene.docs.exclude in .slopstopper.yml, so the docs checks that keep the reference docs routed and sized leave it alone: it is read in order by people, not routed to by agents.
